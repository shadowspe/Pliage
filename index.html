Schéma biais
Activer le schéma biais (pièce qui passe progressivement d'un profil Gauche à un profil Droite)
Dessine le profil Gauche puis le profil Droite avec les mêmes outils que ci-dessus (Séquence du profil). Les deux profils doivent avoir le même nombre de segments, les mêmes types et les mêmes angles/sens de pli — seules les longueurs, rayons et diamètres peuvent différer. Le logiciel interpole progressivement de l'un vers l'autre sur la longueur de la pièce.
